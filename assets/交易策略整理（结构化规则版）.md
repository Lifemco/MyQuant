# 交易策略体系整理（结构化规则版）

> 整理自《交易策略汇总.docx》（文字笔记 + 31 张截图，含「操作手册」十卷、帖子原文、答疑表格、量能口诀）。
> 本文档的目的：把口语化的交易经验拆解为**可编程的规则**，供后续用 Kimi Code 转换为量化/半量化交易策略。
> 每条策略均按统一格式描述：适用场景 → 入场 → 加仓 → 减仓/止盈 → 止损 → 仓位规则 → 涉及指标 → 待量化参数。

---

## 0. 体系总览

原作者将交易者分为三类，策略按流派选用：

| 流派 | 特点 | 对应策略编号 |
| --- | --- | --- |
| 潜伏型 | 低吸高抛，不断滚动，反复做同一只票 | S4 / S5 / S6 |
| 打板型 | 单吊一两只，看连板情绪与连板高度（需龙头战法，风险最高） | S3（部分） |
| 死拿型 | 买入后牛市不结束不打开账户，仅定期核查周/年线趋势、业绩、量能、股东户数，守住关键支撑位，破位才离场 | S1（变体） |

**全局纪律（所有策略通用约束）：**

1. 不存在"卖飞"：任何有利润的减仓都是正确的，吃到预期收益即可。
2. 目标年化仅 8%，不贪心，追求确定性而非"格局"。
3. 任何买入/卖出必须基于规则理由，禁止情绪驱动操作。
4. 逃顶是运气不是能力；要做的是看情绪、看资金、看滞涨、看板块内部一致性。
5. 顺势而为：指数与股价由机构/大资金主导，散户只做跟随。
6. 看好的票可以反复做（高抛低吸），破位就留底仓观察，资金去别处短期套利，到位子再接回。

## S1. 趋势票 5 日线操作法（核心策略，最适合量化）

**适用标的**：两类趋势票——①机构大票；②当年最强板块中的龙头股。特征：沿 5 日线呈约 45° 角上行，调整通常不跌破 10 日线，随后重新沿 5 日线向上。

**信号规则表**（可直接写成 if-else）：

| # | 信号 | 操作 |
| --- | --- | --- |
| 1 | 股价远离 5 日线（乖离率过大） | 减仓止盈一部分 |
| 2 | 跌破 5 日线，但收盘仍在 10 日线之上 | 可接回（加仓） |
| 3 | 跌破 10 日线 | 减仓观察；**跌破 20 日线 → 清仓** |
| 4 | 5 日线上穿 10 日线 + 放量、量价齐升 | 可加仓 |
| 5 | 站稳 10 日线 + 放量齐升 | 可加仓 |
| 6 | 无量突然拉升且不封板 | 减仓；封板则持股看戏 |
| 7 | 连续拉升后滞涨（有成交但涨不动、分时背离） | 逐步减仓，直至清零或仅留底仓 |
| 8 | 慢板块/慢票突然变快 | 看量能：不涨停 → 减仓 |

**术语定义（原手册给出，可直接编码）：**

- **企稳（站稳）**：连续 3 天以上收盘价站上 5 日线，且短期内不跌破前低。否则只是底部反抽。
- **主升浪**：股价突破前方所有压力位，且下方量能持续良性放大（非单日爆量）。
- **支撑位**：主力成本区，即主力与散户都能接受的位置。判定支撑的三要素组合：**密集筹码区 + 金针探底（长下影）+ 板块同步拉升** = 有效支撑的经典组合。
- **支撑位反抽**：在支撑位出现反抽时，要大减仓，不要幻想趋势反转。

**趋势票分层止损线**：一般趋势票以 5 日线为生命线，跌破也应保持在 10 日线之上；短期暴涨票一般在 10–20 日线之间稳住；重大利空跌破 20 日线 → 去看前期筹码密集区。

**术语定义补充（参数已确认，详见第 12 节）：** "远离 5 日线"乖离率初始阈值取 5%（回测后调整）；"滞涨"定义为连续 2 日涨幅 < 1% 且成交量 ≥ 20 日均量；"分时背离"采用 MACD 顶/底背离判定：MACD 前高点 A 高于后高点 B（A>B），但分时价格上 B 高于 A → 顶背离，考虑减仓；反之为底背离，考虑加仓。

## S2. 放量突破加仓策略

**入场/加仓规则：**

1. 突破压力位永远是加仓的时机，宁可试错（原作者经验：成功率约 70%，30% 会被利空砸下来）。
2. **必须放量突破才有效**；无量拉升太危险。看分时红绿柱、成交量（一字板/直接封板除外）。
3. 如果连日线的压力位都突破不了 → 要么主力在憋大招，要么准备砸盘，此时去核查消息面是否靠谱，不加仓。
4. 到压力位没涨停、或没有量价齐升突破的 → 减仓。
5. 只有出现止跌信号 + 到支撑位才可以加仓，**空中飞刀不要接**。

**跳空高开特例**：突破压力位直接跳空高开且不断拉升的，次日成交量至少达到当日的 1.14 倍才能继续拉升；跳空高开后回落很危险，直接减仓。

**压力位识别**：前高、筹码密集区（需筹码分布数据）、N 日最高价均可，具体结合盘面判断（实现时三种都算，输出供人工确认）。

## S3. 拉升出货/滞涨减仓策略（连续上涨票的离场规则）

**适用场景**：票开始突然拉升、连续上涨之后。

**规则：**

1. 看当日分时：**无量突然拉升且不封板 → 减仓**；封板 → 持股看戏。
2. 大票连续拉升后**开始滞涨就减仓**：涨不动、一直有成交但不怎么涨、分时背离 → 减仓。
3. 减仓后继续拉升 → 继续卖，直至清零或只留底仓。
4. 阴跌数月后突然拉涨停（昙花一现型）：可先卖 1/3。
5. 高位横盘后开涨：当日放量**最多只能放倍量**，放量过多 = 昙花一现；且分时不能一下子拉涨停，震荡上行才有后续；涨停后回调幅度不超过涨幅的一半且当天收回，才有二次确认。

## S4. 低位埋伏建仓策略（分批建仓节奏）

**建仓节奏（以 50 万资金为例，可按比例缩放）：**

1. 先判断操作类型：**低位埋伏** 还是 **连续放量看好**，两者操作完全不同。
2. 低位埋伏：日线看好 + 缩量 → 入场先买 **1–2 成仓**。
3. 三日内继续缩量 → 加仓到 **3 成**，之后观察。
4. 连续 15 天未能突破（日线）→ 复盘当初看涨的理由是否还存在；不存在 → 止损止盈退出，或转为中线持有。
5. 试探式建仓示例：看好一只票先小额建仓试探（如 2 万），高位先出 1/3，回调时再补（如补到 1.3 万）。

**仓位总原则：**

- 建仓可以随时，**加仓必须看位置**；最后一笔资金一定是到了位置（支撑/企稳确认）再买，不是跌下来就买。
- 先手重要性：有先手才可以在压力位减仓或做 T；没先手今天买进去明天不一定有溢价。
- 买不到最低点，买到相对低点即可。

**持股数量上限（按资金规模）：**

| 资金规模 | 最多持股数 |
| --- | --- |
| < 2 万 | 1 只 |
| < 10 万 | 2 只 |
| < 50 万 | 3 只 |
| 50–100 万 | 4 只 |
| > 100 万 | 自便（普通散户持仓过多操作不过来，蹲守一两个板块收益更高） |

## S5. 被套自救策略

**被套类型与应对：**

| 被套类型 | 应对策略 |
| --- | --- |
| 短线连板票被套 | 最麻烦，反包概率小；非超高辨识度龙头 → 不用犹豫，直接处理 |
| 急拉趋势票被套 | 一般砸破 10 日线，在 20 日线上方做平台，可自救；没有重大利空的话前高难突破（机构票除外，机构票会横盘后突破前高） |
| 连续趋势票被套 | 机构底仓不动则很难破 5 日线，跌了三天内一般收回；10 日线是底线（突发黑天鹅除外），随后看反拉；没反拉就看机构动向 |
| 超低位横盘票被套 | 10 日线是生命线，恒久必跌（突发利好除外） |

**自救通用步骤：**

1. 低位买进，拉低成本。
2. 拉高到压力位，不突破就减仓；突破再看。
3. 破位之后：第一支撑位低吸一层 → 第二支撑位再吸一次 → 第三次一定是止跌拉升时再介入。
4. 最后一笔资金必然是趋势明朗（企稳反转）后再加。
5. 下跌趋势中分仓进场，等位置和信号（绿变红、十字星、情绪反转）。

**支撑位加仓原则**：支撑位低吸不会错，但若一路下跌则看戏不补；再破位继续减仓（亏掉补仓部分）；到下一个支撑位（平台密集筹码区）继续加仓，极限降低成本。

**黑天鹅事件（贸易战等集体暴跌）**：破位概念不存在（叠加指数暴跌加成），只有低吸一条路：有仓位的暴跌直接加仓，分两次加仓，拉高减仓，来两次完工。目的是降低成本自救，不是获利，果断点，不怕卖飞。

## S6. 做 T 与滚动操作策略

**完美 T 信号**：缩量止跌（下跌量能缩小）+ 分时背离 → 买入机会 → 拉升卖出 = 完美 T。

**做 T 原则：**

1. 做 T 不一定要日内完成，但若因不遵守纪律越套越多，说明执行不到位。
2. 低位连续涨的票：减仓一点，因为必然会有回落震荡。
3. 高位票：不到位置不敢买。
4. 慢的板块突然变快：立刻看量能减仓降本。

## S7. 板块轮动策略

**一轮行情的四波节奏（大框架）：**

1. 第一波：机构主导（算力、机器人、医药等）。
2. 第二波：轮动拉升（每个板块跑一遍）。
3. 第三波：大票补涨（中字头、指数票拉升）。
4. 第四波：消灭低价股。然后周而复始（板块次序可能变动，但虽迟会到）。

**轮动操作铁律：**

1. 只吃鱼头布局 + 鱼身主升，坚决舍弃鱼尾行情，行情走完果断换板块。
2. 若旧板块重回趋势支撑线上，可再度买回重复操作（原作者两年内同一标的 7 进 7 出）。
3. 附加技术校验：MACD 金叉、站稳日线、守住趋势线；区分是主动破位还是被指数/板块被动带崩。
4. 板块抱团规则：板块总龙头不启动，绝不加仓跟风个股。

**板块效应 vs 个股效应**：板块效应看未来趋势（是个周期）；个股效应看封板、拉升是否有量。要区分个股是独立行情还是板块共振。

**个股/板块选择八分类**（不同类型不同打法）：①年度强势新题材（算力、机器人）②稳如老狗的红利（银行、证券、保险、基建、有色、化工）③政策利好叠加（低碳、消费、基建、AI 应用）④边缘冲突（军工、黄金、农业）⑤机构喜好（白酒、医药）⑥国企央企改革+概念（叠加重组爆发力极强）⑦其他细分（互金、换电、固态电池等）⑧周期性板块（猪肉、鸡肉、光伏）。

**慢牛/大势判断**：存款搬家、资本流动、化债需要一轮慢牛；上涨分两个阶段——所有低位股轮动拉升 → 震荡走高后回调、再启动第二轮拉升，部分趋势股继续走趋势。

## S8. 情绪指标（反向指标，定性使用）

| 市场/评论区状态 | 操作信号 |
| --- | --- |
| 开始秀战绩、晒收益 | 提醒自己该谨慎了 |
| 还在骂 | 可以准备进场 |
| 死气沉沉 | 可以重仓收米 |

- 情绪一致性卖出信号：板块后排涨了三天、龙头一直在涨、情绪非常一致 → 一键卖出。可能会卖错，但那是认知内的钱。
- 情绪低点是 A 股特别硬核的技术指标。
- 注意：此类指标难以直接量化，可作为人工复核项或舆情因子，不建议第一版就自动化。

## 10. 量能判定标准（来自答疑，阈值明确，可直接编码）

| 维度 | 规则 |
| --- | --- |
| 量比 | >1.5 = 放量；>2.5 = 强；>5 = 警惕 |
| 5 日均量 | 当日量 > 1.5 倍 = 有效；> 2 倍 = 强 |
| 位置 | 突破必须放量；下跌放量 = 真跌 |
| 配合 | 放量涨 = 好；缩量涨 = 危险；放量跌 = 弱 |
| 持续性 | 连续 3 天放量 = 真强；单日爆量 = 假强 |

**一句话口诀：放量突破买，缩量新高卖，放量下跌跑。**

| # | 参数 | 确认值 |

| 1 | "远离 5 日线"乖离率阈值 | 初始 5%，在自选票中回测后确定 |
