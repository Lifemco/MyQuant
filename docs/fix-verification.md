## 验证

## 保留的边界

- 交易所收盘确认采用保守时间规则，没有完整节假日/半日市日历；相应信号可能延后确认。详见 README。
- 复权历史重建可能缩短历史到数据源返回的窗口，旧数据保存到最近一次 `.parquet.bak`。不自动猜测复权因子。
- 美股仍为日线缓存，不新增实时行情源。真实连接已尝试，腾讯/Yahoo 请求被当前云环境代理以403阻断，尚未验收真实数据返回；详见 live-market-verification.md。
- 回测不模拟滑点、税费差异、最小佣金、整手数量或涨跌停成交约束。
- GitHub Actions 在推送和拉取请求时执行相同的自动检查，运行结果可在仓库 Actions 页面查看。
