# K线终端与左侧导航

全局导航位于最左侧，桌面可收起为图标栏，手机保持左侧窄栏。行情自选列表是独立的可折叠区域，手机默认收起，展开后覆盖内容而不挤压图表。

新版K线借鉴手机行情终端的布局与交互：白底细网格、红涨绿跌、阳线空心/阴线实心、非平滑均线，主图占主要空间；成交量常驻，MACD/KDJ切换，支持只保留成交量。与旧版同时展开三个大副图、主图仅约17.5%的布局不同。

- 默认显示桌面最近70根/手机最近40根，避免全部历史挤成细线；`＋`/`−`缩放，复位回到最近行情。
- 鼠标/触控横向拖动查看历史，滚轮/双指缩放；长按进入十字线检查，移动后同步更新上方日期和开高低收、涨跌幅及副图数值。
- 提供显式十字线按钮。图表聚焦后可用左右方向键逐根检查，全屏后按Escape退出。
- 主图和副图的时间轴与缩放联动。数据量不足的均线显示缺失，不插值编造；成交量单位由行情元数据决定，未知时不猜测手/股。
- B/S仍为收盘策略信号，不代表已成交。买点标在对应K线下方、卖点标在上方。

自动浏览器验证使用标明“合成验证数据”的180根测试K线，覆盖副图切换、缩放复位、键盘检查、全屏、手机触摸长按及左侧导航；截图不作为真实行情返回证明。
