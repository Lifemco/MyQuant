# 自然语言策略工作室

入口：**策略中心 → 策略创作工作室**。原有批量回测、参数寻优和行情下载保留在下方的内置策略实验室。

## 工作流程

1. 在后端配置`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，选择的服务需支持OpenAI兼容`/chat/completions`及JSON对象输出。配置位置/SDK、超时、路径和请求参数都在`backend/app/data/third_party.py`的`AGENT_SETTINGS`及`strategyAgentRequest`。目前默认45秒超时、3000输出token、最大1MiB响应，不跟随重定向发送密钥。
2. 用大白话写入场、退出、风控和因子需求，点击 **让Agent整理策略**。助手返回中文总结、结构化规则、待补充问题与未支持内容。存在问题/未支持内容时页面禁止保存和执行该草稿，不能省略一部分需求就声称已实现。
3. 核对并编辑条件。每组支持全部满足AND或任一满足OR，每组最多12个条件；也可通过 **JSON规则** 编辑完整策略。JSON必须经后端schema校验才进入编辑器，不接受任意Python代码。
4. 保存到策略库，按版本继续编辑或另存。并发保存使用版本校验，过期版本返回409，防止覆盖其他页面的修改。
5. 选择最多20只已缓存标的，点击 **执行回测 / 计算信号**。各股独立回测，显示收益、回撤、净值与最新收盘目标/买卖点；不连接交易账户，也不是自动组合调仓。

模型未配置时，页面明确显示待配置状态，条件编辑器、示例和手动规则仍然可用。示例不会被冒充成模型生成结果。用户本次选择后补真实服务配置，因此目前模型协议使用模拟响应验证，尚未验收真实模型服务。

本地可复制`.env.example`为被Git忽略的`.env`，填写模型配置，再在当前终端使用`set -a`、`. ./.env`、`set +a`加载你自己的配置后执行`./start.sh`；启动脚本不会自动读取`.env`。数据目录可不设置，避免因相对路径变化看不到原缓存。K8s使用ConfigMap/Secret，见云部署说明。

## 可组合条件

| 输入 | 口径 |
| --- | --- |
| 开/高/低/收、成交量 | 标的缓存日线口径；已确认收盘后计算 |
| SMA | N日简单均价，N在2至252之间 |
| RSI | N日简单滚动涨跌均值的RSI，非Wilder平滑版本 |
| 收益率 | `close / close.shift(N) - 1`，小数 |
| 年化波动率 | 日收益样本标准差乘`sqrt(252)`，小数 |
| N日回撤 | 收盘价相对过去N日滚动最高收盘价的回撤，负小数 |
| 量比 | 当日量除以前N日均量，分母不含当日 |
| 外部因子 | 用户导入的估值、财务、情绪、宏观或事件指标，按实际可知时间匹配；可自由命名 |

比较支持大于/大于等于/小于/小于等于/向上穿越/向下穿越，左右两端均可选择因子或常数。窗口未预热、缺值或因子过期时，该条件为假；没有自动填0。外部因子整份缺失时该标的执行失败，并明确报告所缺因子。

退出优先于入场。收盘止损、止盈基于实际下一交易日买入开盘价，触发后于下一根日线开盘退出；不是盘中止损，也不保证止损价成交。可设置最长持仓交易日；清空风控输入或JSON中填null可关闭对应约束。回测继承既有现金/股数、T+1和单边费用逻辑。

未支持的组合权重、跨标的排名、做空、杠杆、自动抓新闻和实盘下单由Agent列入未支持内容。新执行器只解释已列出的受约束规则，不执行模型输出的代码。若需要更复杂模型，可在后端新增有明确数据契约的因子/算子，再扩展schema。

## 财务、事件等外部因子

在 **外部因子数据** 选择标的、因子名（如`pe_ttm`、`sentiment`、`revenue_yoy`、`event_score`）、来源/计算方法，导入CSV或JSON。示例：

```csv
availableAt,value
2024-01-02T10:00:00+08:00,18.2
2024-04-26T18:00:00+08:00,17.5
```

`availableAt`必须包含时区，是该值真实公开/可用的时间，不是财报所属期或事件发生但尚未公布的时间。A股15:00后公布的信息最早在下一交易日的收盘策略计算中使用；美国日期按纽约时区及夏令时处理。匹配只向过去查找，并受每个外部因子的`maxAgeDays`（1至366天）限制。日期不带时区、重复发布时间、非有限数值或无效因子名都会拒收。

每个标的/因子保存独立完整序列，导入会替换该因子旧序列；不要只上传一条增量而误删既有历史。财报修订必须按修订公开时点提交新观察值，不把修订后的值覆盖回原发布时间。数据真实性和单位来自所填数据源，目前不自动获取财务或新闻。回测和最新信号共享同一份因子快照，避免两次读取之间数据变更。

策略库和因子存于`QUANT_DATA_DIR/strategies/`，已加入Git忽略规则并挂载持久卷；模型密钥不在策略数据中。主要API为`/api/strategies/capabilities`、`draft`、`validate`、`library`、`factors`和`execute`。
